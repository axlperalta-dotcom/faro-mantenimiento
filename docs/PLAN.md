# Plan de entregas

## Entrega 01 · Expediente y evidencia (implementada)

Historia: como técnico, quiero registrar una incidencia, consultar fuentes y guardar mi revisión para continuar la investigación más tarde.

Criterios: persistencia al reiniciar; PDF/TXT adjuntable; búsqueda limitada al caso; referencia exacta de página; estados y notas editables; mensajes para archivos inválidos; ejecución sin credenciales ni GPU.

## Entrega 02 · Reporte con trazabilidad

Avance: ficha de cierre estructurada implementada; tres expedientes sintéticos disponibles para practicar observación, investigación y cierre. Las referencias todavía se escriben manualmente y no se validan automáticamente.

- Seleccionar fragmentos como evidencia de una observación o hipótesis.
- Construir un borrador de reporte con observaciones, datos pendientes, hipótesis y referencias.
- Mantener distinción explícita entre texto extraído, texto generado y revisión humana.
- Agregar historial de cambios al estado y notas.

## Entrega 03 · Evaluación de recuperación

- Seleccionar una familia de equipos según fuentes reutilizables disponibles.
- Crear preguntas y evidencia correcta con revisión humana.
- Separar los documentos para desarrollo de los de prueba final.
- Medir recuperación de evidencia, falsos positivos y tiempo de respuesta.
- Comparar búsqueda léxica con una alternativa; publicar fallos y limitaciones.

## Entrega 04 · Integración LLM

Resolver primero acceso, presupuesto y documentos permitidos. Respuestas citadas y rechazo cuando falte evidencia. Medir errores de cita y afirmaciones sin respaldo. No se presupone que la suscripción de Codex cubra llamadas de una aplicación propia.

## Entregas posteriores

Proceso de ingestión aislado, pruebas de carga, autenticación, despliegue, prueba con usuarios, documentación para entrevistas y contribuciones externas cuando tengan sentido.

Horizonte orientativo: seis meses. Se trabaja por entregas verificables; los límites del plan no equivalen a horas de aprendizaje. Al terminar cada sesión, registrar avance, pruebas, dudas y siguiente tarea.
